# KRI Online — PHP Social Media Web Application

**KRI Online** is a PHP-based social media web application developed using PHP, JavaScript, HTML and CSS.

The project demonstrates the development of a server-rendered web application with user-facing social features and image upload functionality.

## Project Overview

KRI Online is a practical web development project focused on building a social media-style platform using traditional PHP web technologies.

## Key Features

- Social media web application
- PHP backend
- JavaScript interactions
- HTML and CSS interface
- Image upload functionality
- User-facing web pages
- Local development with XAMPP

## Technology Stack

- PHP
- JavaScript
- HTML5
- CSS3
- XAMPP

## Local Development

The project can be run locally using XAMPP.

1. Copy the project into the `htdocs` directory.
2. Start the PHP server through XAMPP.
3. Open the application in a browser.
