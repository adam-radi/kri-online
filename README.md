# Social Media App

Simple social media web app built with PHP, JS, CSS, and HTML.

## How to run locally

1. Copy the project to `htdocs` folder in XAMPP.
2. Open `index.php` in browser.
3. Make sure your PHP server is running.

## Notes

- `uploads/` folder is ignored in Git.
- Add your images locally to `uploads/` to test features.
